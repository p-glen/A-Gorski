# Client Check

Rejestr rzeczy do potwierdzenia z klientem (adwokatem). Budujemy według najlepszych praktyk, a każde odstępstwo od przysłanego tekstu, założenie lub niepewny fakt dostaje tu wiersz. Całość wysyłamy klientowi jedną paczką.

Statusy: **sprawdzone przez nas** (ze źródłem), **częściowo** (potwierdzone w części), **do klienta** (nie umiemy potwierdzić sami).
